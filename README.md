# Save the Earth 

A browserbased clicker game where you defend Earth from real-world environmental threats.

About

Earth sits at the center of space while threats; Pollution, Global Warming, Deforestation, and Plastic Waste .Spawn from the edges of the screen and drift toward it. Click each threat before it reaches Earth to destroy it and score points. If a threat hits Earth, it takes damage. Survive as long as you can and rack up the highest score before Earth's health runs out.

This was built as my project for Hack Club's "Give Your Website a Pulse" mission; a custom new tab page covering layout, styling, and interactivity.

How to Play

1. Open index.html in your browser (or visit the live demo below)
2. Read the instructions on the start screen
3. Click Start Game
4. Click each threat before it reaches Earth
5. Survive as long as possible;if Earth's health hits zero, it's game over
6. Click Try Again to restart

Built With

HTML
CSS
JavaScript (vanilla, no frameworks or libraries)

 Features

- Start screen with full game instructions
- Real-time health bar tracking Earth's status
- Live score counter
- Threats spawn from random edges and drift toward Earth using distance-based movement
- Pop/burst visual effect when a threat is destroyed or hits Earth
- Game over screen with final score and a restart button, fully replayable without refreshing
